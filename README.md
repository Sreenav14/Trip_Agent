Trip Agent - AI Travel Planner
A travel-planning assistant that generates detailed, tool-assisted travel itineraries and expense breakdowns using an agentic workflow. It combines an LLM with modular tools (places, weather, currency, expense calculators) and exposes a FastAPI backend and a Streamlit UI for easy interaction.

Key capabilities

Day-by-day itinerary generation (two versions: mainstream + off-beat)
Hotel, activity, restaurant and transportation recommendations
Real-time weather lookups and forecasts
Currency conversion and cost/expense estimates
Downloadable travel plan (Markdown + optional PDF)
Modular tool architecture so you can add custom integrations
